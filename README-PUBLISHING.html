CHEMOSPHERE 2026

Publishing guide for your animated invitation and QR-code generator using free GitHub Pages hosting.

Create GitHub repository Open GitHub

1. Files to upload

  • index.html — your animated CHEMOSPHERE invitation. This is the homepage visitors see after scanning.
  • qr-maker.html — creates and downloads the QR code after the site is published.
  • README-PUBLISHING.html — this publishing guide (optional to keep in the repository).

Keep all files in the repository's top-level (root) folder. Do not put index.html inside another folder.

2. Create the repository

1
Sign in to GitHub as nasifjishan28-tech (or the account that will own the website).
2
Choose New repository. Enter the repository name chemosphere-2026.
3
Set visibility to Public for GitHub Free Pages hosting. Select Create repository.

3. Upload the website files

4
Inside the new repository, choose Add file → Upload files.
5
Upload index.html, qr-maker.html, and optionally README-PUBLISHING.html. Confirm the filenames are exactly as written.
6
Scroll down and choose Commit changes.

4. Enable GitHub Pages

7
Open the repository's Settings tab, then select Pages in the left sidebar.
8
Under Build and deployment, set Source to Deploy from a branch.
9
Choose branch main and folder /(root), then select Save.
10
Wait for the deployment to finish. GitHub Pages will show the published website address in Settings → Pages.

Expected URL for this account and repository: https://nasifjishan28-tech.github.io/chemosphere-2026/. This is only an expected address; use the exact URL GitHub Pages displays after successful deployment.

5. Generate the final QR code

11
Open the QR maker page at https://nasifjishan28-tech.github.io/chemosphere-2026/qr-maker.html after deployment.
12
Paste the exact published invitation homepage URL into the input field and tap Generate QR code.
13
Tap Download PNG. The file will be named CHEMOSPHERE-2026-QR.png.
14
Scan the PNG from another phone. Confirm it opens the invitation, the Enter button works, and the animation and sound behave as expected.

Important before printing

  • Do not generate or print the final QR until GitHub Pages shows the site is live.
  • Use the homepage URL in the QR, not the QR-maker URL.
  • Do not rename the repository or change its Pages URL after printing.
  • Keep the repository public if using GitHub Free Pages.
  • The QR maker loads a QR-code JavaScript library from a CDN, so an internet connection is required when generating the QR.
  • GitHub Pages is static hosting; no backend or paid API is needed for this invitation.
