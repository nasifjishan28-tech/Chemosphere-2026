# CHEMOSPHERE 2026 — GitHub Pages

## Files
- `index.html` — animated CHEMOSPHERE invitation homepage.
- `qr-maker.html` — generate and download a QR PNG after the website is live.
- `README-PUBLISHING.html` — visual publishing guide.

## Publish with GitHub Pages
1. Sign in to GitHub as `nasifjishan28-tech`.
2. Create a **Public** repository named `chemosphere-2026`.
3. Upload all files to the repository root (not inside a subfolder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then Save.
7. Wait until GitHub Pages reports a successful deployment.

Expected invitation URL (verify it in Settings → Pages):
`https://nasifjishan28-tech.github.io/chemosphere-2026/`

## Generate the QR
After deployment, open:
`https://nasifjishan28-tech.github.io/chemosphere-2026/qr-maker.html`

Paste the exact homepage URL shown by GitHub Pages, choose **Generate QR code**, then **Download PNG**. Scan-test it from another phone before printing.

**Important:** The QR must contain the homepage URL, not the QR-maker URL. Do not print until the website is live and tested.

Official documentation: https://docs.github.com/en/pages/quickstart
